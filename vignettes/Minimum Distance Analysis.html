Minimum Distance Analysis

Overview

This tutorial walks through spatial minimum distance analysis using scSpatial. The analysis computes the minimum distance from a cell of interest to the nearest cell in a reference population, which represents a tissue structure or landmark.

When to use minimum distance vs. colocalization

scSpatial provides two complementary spatial analyses:

Colocalization Minimum Distance
Method Sums Gaussian field values from all reference cells Finds the distance to the nearest reference cell
Question “How enriched is this cell in a cell-type neighborhood?” “How close is this cell to a tissue structure?”
Best for Cell–cell attraction/repulsion, where more reference cells produce a stronger signal (chemotaxis) Spatial regionalization, where the cell’s position relative to a tissue boundary matters regardless of the number of cells defining it

Why use minimum distance here? Consider myeloid cells (MC_CD14) distributed across a tissue section. Their distribution is largely determined by the tissue region they reside in (epidermis vs. dermis vs. immune aggregates), not by how many reference cells attract them. Summing colocalization scores would make some regions appear artificially “hotter” simply because they have more reference cells. Minimum distance avoids this by capturing only the proximity to the nearest structural landmark.

Step 1: Compute minimum distances

calcMinDistance() iterates over every image and computes the Euclidean distance from every cell to the nearest reference cell. You specify reference cell types as either a character vector (for one reference population) or a named list (for multiple reference populations computed at once).

# Compute minimum distance to multiple reference populations at once
dist.values <- calcMinDistance(
  srt,
  celltype.col = celltype.col,

  # Named list: each element defines a reference population
  ref.celltypes = list(
    KC_basal      = c("KC_basal"),
    CD4_CD8       = c("CD4", "CD8"),
    FB_proInf_sup = c("FB_proInf_sup"),
    FB_proInf_deep = c("FB_proInf_deep")
  )
)

)

Step 2: Two-structure analysis

The key insight of minimum distance analysis is that cells can be positioned relative to two tissue structures simultaneously. By plotting the minimum distance to structure A on the x-axis and to structure B on the y-axis, you create a 2D spatial coordinate system that reveals which tissue compartment each cell resides in: - Cells near structure A cluster near the x = 0 line - Cells near structure B cluster near the y = 0 line - Cells between the two structures spread across the diagonal

Coloring by a cell state or transition score reveals how cell phenotypes map onto these tissue compartments.

plotWithMargin(): scatter with margin trend panels

plotWithMargin() creates a scatter plot with loess trend panels on the left and bottom margins. The margin panels show how the color variable (e.g., transition rank) changes along each axis, summarizing the spatial trend.

Example 1: Epidermis (KC_basal) vs. Immune aggregates (CD4/CD8)

df.plot <- df.mc[!is.na(df.mc$minDist_KC_basal) &
                 !is.na(df.mc$minDist_CD4_CD8) &
                 !is.na(df.mc$transition_rank), ]

plotWithMargin(
  df.plot,
  x.by     = "minDist_KC_basal",
  y.by     = "minDist_CD4_CD8",
  color.by = "transition_rank"
)

In this plot: - Bottom-left corner: MC_CD14 cells near both the epidermis and immune aggregates - Bottom-right: cells far from the epidermis but near immune aggregates (deep dermis) - Top-left: cells near the epidermis but far from immune aggregates (superficial dermis) - The margin panels show the loess trend of transition rank along each axis — if the transition is spatially organized, the loess curve will show a gradient

Putting it all together

Here is the complete workflow in a compact script:

library(Seurat)
library(scSpatial)

# ---- Load data ----
srt <- readRDS("path/to/seurat.rds")
celltype.col <- "CellType"

# ---- Step 1: Compute minimum distances ----
dist.values <- calcMinDistance(
  srt,
  celltype.col  = celltype.col,
  ref.celltypes = list(
    KC_basal       = c("KC_basal"),
    CD4_CD8        = c("CD4", "CD8"),
    FB_proInf_sup  = c("FB_proInf_sup"),
    FB_proInf_deep = c("FB_proInf_deep")
  )
)

# Save results
write.csv(dist.values, "min_distance_values.csv")

# ---- Step 2: Add to metadata & subset ----
for (col in colnames(dist.values)) {
  srt@meta.data[[paste0("minDist_", col)]] <- dist.values[colnames(srt), col]
}

df.mc <- srt@meta.data[srt@meta.data[[celltype.col]] == "MC_CD14", ]

# ---- Step 3: Single-structure plots ----
ggplot(df.mc, aes(x = subCellType.pub1.1, y = minDist_KC_basal,
                  fill = subCellType.pub1.1)) +
  geom_violin() + geom_boxplot(width = 0.15) +
  theme_bw() + theme(axis.text.x = element_text(angle = 45, hjust = 1))

# ---- Step 4: Two-structure plots ----
plotWithMargin(df.mc,
               x.by = "minDist_KC_basal", y.by = "minDist_CD4_CD8",
               color.by = "transition_rank")
ggsave("minDist_KC_basal_vs_CD4CD8.pdf", width = 7, height = 6)

plotWithMargin(df.mc,
               x.by = "minDist_FB_proInf_sup", y.by = "minDist_FB_proInf_deep",
               color.by = "transition_rank")
ggsave("minDist_FB_proInf_sup_vs_deep.pdf", width = 7, height = 6)
